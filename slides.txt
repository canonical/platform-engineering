Every action that has to be repeated on more than 5 repositories has as a skill

A PR MUST be created on canonical/platform-engineering with:
A doc, spec, or KB entry with the context and the team contact.
A “validator” to check if a repo is compliant or not
First version does not have to be complete.
Validators are versioned.
Validators can be run via “uvx” on any repo
A skill to execute the work
It may just be a one-line prompt.
Skills are versioned
A charmkeeper recipe to be able to apply the skill on multiple repos
