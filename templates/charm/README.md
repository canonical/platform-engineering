# Charm template

Copier template for Kubernetes charms. Imported from `platform-engineering-charm-template`
at commit `13ea9a8` and made copier-friendly.

See [`../README.md`](../README.md) for usage. Questions are defined in [`questions.yml`](questions.yml) (included by the root
`copier.yml`), sources are in [`template/`](template/).
