# Security policy

## Supported versions

This repository contains public Platform Engineering team documentation,
agent skills, validators and templates. Tagged releases of the validators and
actions are meant to be pinned by consumers; only the latest release is
supported.

## Reporting a vulnerability

The easiest way to report a security issue is to open this repository's
**Security** tab and choose **Report a vulnerability**. The report stays
private until a fix is available.

You may also send email to security@ubuntu.com. If you want to encrypt your
email, follow [Canonical's reporting instructions][contact].

[contact]: https://ubuntu.com/security/disclosure-policy#contact-us
